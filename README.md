# Student Performance AI

An end-to-end AI Engineering project for predicting student academic performance using PyTorch.

## Goals

- Understand and explore educational data
- Build a robust preprocessing pipeline
- Train a neural network for prediction
- Evaluate model performance
- Develop a Streamlit-based prediction interface
- Deploy the application

## Tech Stack

- Python
- PyTorch
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
